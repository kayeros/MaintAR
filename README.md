# MaintAR

Мобильный помощник инженера на обходе оборудования. Находит оборудование по QR-коду или серийному номеру, показывает карточку с узлами и их ресурсом. ИИ отмечает дефекты на фото, а работы записываются в журнал.

Хакатон «Кибер 102», кейс КСТ Энерго Инжиниринг, команда GitPotam.

## Что умеет

- Поиск оборудования по QR-коду, по номеру с шильдика или вручную из списка.
- Карточка оборудования: паспорт, узлы с остаточным ресурсом, блок «Сначала проверьте».
- Фото узла: ИИ рисует рамки дефектов и даёт пояснение с рекомендацией. Нажатие на рамку открывает узел.
- Экран узла: нормативный срок службы, расчётный остаток, фактическое состояние по фото.
- Журнал работ («Проверил», «Обслужил», «Заменил», «Заметка») и история осмотров всех инженеров.
- Вход и регистрация с подтверждением почты, восстановление пароля.

## Как запустить

Нужны .NET 11 SDK, Python 3.12+, Node.js 20+ и телефон с Expo Go, подключённый к той же сети Wi-Fi, что и компьютер.

1. Скопируйте `backend\MaintARBackend\appsettings.Local.example.json` в `appsettings.Local.json` и впишите ключи. `Jwt:Key` — любая строка от 32 символов.
2. В `.env` укажите IP компьютера: `EXPO_PUBLIC_API_URL=http://<IP ПК>:5176` (образец в `.env.example`). Выполните `npm install` и запустите `start-all.bat`: откроются окна ИИ (8000), сервера (5176) и Expo (8081).
3. В Expo Go откройте `exp://<IP ПК>:8081`.

Если телефон не видит сервер, откройте порты в брандмауэре Windows:
`netsh advfirewall firewall add rule name="MaintAR" dir=in action=allow protocol=TCP localport=8081,5176,8000 profile=private,public`

## Вход

- Логин `demo`, пароль `demo12345` — учётная запись демо-базы.
- Или зарегистрируйтесь. В режиме разработки код подтверждения выводится в консоль сервера.

## Коды для проверки

`MOTOR-001` (электродвигатель), `VALVE-001` (задвижка), `TRANS-001` (трансформатор). QR-картинки лежат в `docs/qr`.

## Структура

- корень (`App.js`, `src/`) — мобильное приложение (React Native, Expo);
- `backend/` — сервер (ASP.NET Core, SQLite);
- `ai_service/` — сервис ИИ (YOLOv8).

## Ограничения

- Модель уверенно находит коррозию. Остальные классы дефектов пока недообучены.
- Рамки рисуются на снимке, а не в живом видео.
- Датчики и уставки не подключены.
