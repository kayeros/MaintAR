# Обходчик

AR-помощник инженера для диагностики промышленного оборудования. Мобильное приложение на React Native (Expo).
Хакатон «Кибер 102», кейс КСТ Энерго Инжиниринг, команда GitPotam.

## Что умеет

- Узнаёт агрегат по QR-коду (камера) или по ручному выбору.
- Показывает цифровую карточку: характеристики, узлы, нормативы, расчёт остаточного ресурса.
- Показывает показания датчиков из баз кейса с уставками и графиком за 96 часов.
- Подсказывает, на какие узлы навести камеру, по датчикам и ресурсу.
- Снимает фото узла, рисует рамки дефектов поверх снимка, открывает карточку узла по нажатию на рамку.
- Выдаёт диагноз по правилам «камера + датчики» со статусом, объяснением и рекомендацией.
- Сохраняет результат осмотра («Проверено», «Дефект», «Заменено») в историю. Замена обнуляет наработку узла.

## Запуск

Нужен Node.js 20 или новее и телефон с приложением Expo Go (Google Play или App Store).

```
npm install
npx expo start
```

В терминале появится QR-код. На Android его сканируют из Expo Go, на iPhone штатной камерой.
Телефон и компьютер должны быть в одной сети Wi-Fi. Если не подключается, запустите `npx expo start --tunnel`.

Проверка в браузере без телефона: `npx expo start --web` (камера и QR там работают ограниченно).

Сборка APK: `npx eas-cli@latest build -p android --profile preview` (нужна учётная запись Expo, сборка идёт в облаке).

## Анализ фото

Приложение работает и без сервера: дефекты можно отметить вручную, а для трёх примеров из кейса есть готовая разметка.

Для автоматического анализа укажите адрес сервиса в «Настройках». Приложение шлёт `POST <адрес>/analyze`
(multipart: `photo`, `unit_id`) и ждёт ответ:

```json
{
  "equipment": "что на фото",
  "findings": [{"cls": "shaft_seal_leak", "confidence": 0.86, "box": [0.40, 0.45, 0.20, 0.40], "explanation": "что видно"}],
  "nodes": [{"comp": "seal", "box": [0.38, 0.42, 0.22, 0.42]}]
}
```

`cls` берётся из `src/data/rules.json` (раздел `visual_rules`, поле `class`). `box` задаётся долями кадра:
левый верхний угол `x, y`, затем ширина и высота. Находки с уверенностью ниже 0,4 приложение отбрасывает.

## QR-коды агрегатов

Готовые картинки лежат в `docs/qr`. Содержимое: `PUMP:CN-1` и `PUMP:AMS-21031004-1`.

## Где что лежит

| Файл | Содержимое |
|---|---|
| `App.js` | экраны и навигация |
| `src/engine.js` | движок правил, расчёт ресурса, проверка ответа сервиса |
| `src/data/rules.json` | 5 правил по датчикам, 18 визуальных дефектов, 9 комбинированных правил |
| `src/data/sensors.json` | 500 часовых записей вибрации и температуры из баз кейса |
| `src/data/units.js` | карточки агрегатов, сценарии датчиков, примеры фото |

## Ограничения

- Анализ по фото предварительный. Отсутствие видимых дефектов не подтверждает исправность.
- Метки дополненной реальности рисуются поверх снимка, а не поверх живого видео.
- Карточка ЦН-1 учебная: наработка и нормативы узлов заданы для примера. Карточка AMS заполнена по паспорту.
- История хранится на телефоне.
- Датчики читаются из записанной базы, момент времени выбирается вручную.
